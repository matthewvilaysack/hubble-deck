Field notes

standing context worth keeping in view

Every merge to main deploys

Main auto-deploys to production about ten minutes after merge. There is no manual gate, so a merged PR is a shipped PR.

Mobile web is not in CI

The responsive layouts have no test job, so a green CI run says nothing about them. Verify below 1280px by hand.

Staging seed resets nightly

Anything created on staging disappears at 02:00 UTC. Reproduce bugs before midnight or note the exact steps in the ticket.

ATLAS-149 cause is already found

Uploads over 5 MB hit the proxy's default body limit, not the app. The one-line config fix is written; it ships with the next infra PR.

Owner is now Admin

Main just picked up the rename, UI terminology and the built-in role both. Expect role-name checks in older tests to churn.

Payments vendor sandbox is flaky

ATLAS-121 is blocked on their side. Their status page undercounts; trust the ticket thread over the dashboard.
